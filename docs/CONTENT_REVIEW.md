# 题库编审与发布

| 文件 | 维护内容 |
| --- | --- |
| `content/topics.json` | 14 个已批准专题，数组顺序对应菜单顺序 |
| `content/sources.json` | 来源、出版机构、文书与网页日期、施行日期、可获取状态 |
| `content/knowledge-points.json` | 原子事实、判断范围、主专题、依据条页段 |
| `content/questions.json` | 题干、稳定选项 UUID、答案集合、解析、证据和两轮审查 |
| `content/duplicate-reviews.json` | 新库重复候选对的处置 |
| `content/practice-reviews.json` | 依据真实卷面，对每个已指纹化题干和选项的考法复审 |
| `research/review/legacy-candidates.csv` | 旧候选的审查记录 |

创建题目和选项时生成 UUID。修订、移动专题和调整位置沿用原题 ID。如内容改成另一个考点，新增题目并保留旧条目为 `withdrawn`。判分使用选项 UUID。

## 每题发布步骤

1. 先从校方试卷和官方自测确定设问和常考事实，再从来源台账取现行原文，核实适用时间和条段。轮次、考试对象和证据层级单独记录。对跨卷反复出现且在重大范围内的考点优先覆盖。
2. 作者检查题干、全部选项、正确集合、总解析及逐项理由。第二轮先独立据原文解题，再对照初审结果和解析。审题依据和结果写进 JSON。
3. 校验审核卡的内容摘要。修改题干、选项、排序、解析或证据时，新的摘要要求新的复审。编审可以用 `questionRevision` 得到所审内容的摘要。
4. 对规范化重复、字符三元组召回和同知识点相似题进行核定。将丢弃项标记为 `withdrawn` 或留在候选台账，将可独立考查的题对写入重复核查记录。
5. 事实双审通过后标为 `ready`，再核对考点本身是否适合练习和实际设问。凡范围不合、空泛、干扰项失真或留有歧义的题，按真实卷面改编、有依据地替换或剔除。正式发布同时要求考法复审。线上发布设置 `REQUIRE_COMPLETE_BANK=1`，数据库同步使用 `--release`。

校方原卷、参考答案和复习资料按证据级别计入。广州城建、湖北经济学院、武汉东湖学院及四川大学材料重复出现入党誓词、党章的行动指南、党的最高领导机关、入党条件、个别吸收原则等。短选项来自这类原文留空考法，审题需要同时判断考点和术语。 [完整考法证据与高频矩阵](../research/review/EXAM_STYLE_EVIDENCE.md)

情绪线索题和全选多选题的上限均为 10%，对全库和各专题分别计算。四选单选报告总体位置分布，对可重排题执行任务书第 7 节的计数范围，保留日期、数值和流程选项的自然顺序。四选多选分别统计正确项数量与正确位置，其他选项数量独立报告。程序验证记录完整性及指标，事实复核证据保存于每题。

## 本轮边界

在首轮 103 道工作题中，96 道完成事实双审。按实卷考法逐题检查，16 道适合原样保留，61 道需精简，26 道需重写。后续改稿按新题面重新盲审。审阅命令 `npm run content:review` 导出所有当前题目的 JSON，包含每个选项原文、答案、逐项解释、出处和考法处置。 [考法审查 I](../research/review/style-audit-batch-a.csv) · [考法审查 II](../research/review/style-audit-batch-b.csv)

旧库的 2,115 条主表候选已逐条记录处置。545 道保留为编审候选，280 道需改写，220 道需确认适用范围，250 道旧题因全选淘汰，45 道的旧答案与原文有冲突。保留或改写的候选还要按每题发布步骤完成正式编审。

截至本次快照，167 道工作题分布在全部 14 个专题，其中 165 道完成事实双审、131 道通过考法复核。131 道练习题中有 101 道四选单选，可重排的正确位置计数为 A22、B19、C19、D22，包含自然顺序题的总体计数为 A23、B28、C27、D23。四选多选的两项和三项正确题各 15 道，情绪线索题及全选题均为 0。

事实双审题覆盖全部已登记核心点。练习池仍缺其中 33 个核心点，34 道事实双审题待改稿后再次核查。可通过审阅 JSON 查看每道题的当前题面、完整选项、逐项解析和尚待执行的考法修订意见。已同步到本地运行预览及 Neon 开发库的快照为 82 道。正式发布门禁继续生效。
