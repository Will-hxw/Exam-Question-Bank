## 浏览器实测流程

| 模块 | 实测行为 |
| --- | --- |
| 导航 | 从左到右为刷题、模拟考试、总题库、错题集、收藏夹。标题链接在旧站指向 `https://12371.cn/special/zxzc`，重构使用 `https://www.12371.cn/special/zxzc/`。 |
| 练习入口 | 切换专题下拉选择、随机、顺序、错题、收藏均可加载题卡。顺序模式可下一题、上一题、跳到指定序号，越界不跳。单选只保留一个选项，多选可选中及撤销多个选项。见[专题下拉](baseline/topic-menu-390-light.png)。 |
| 作答反馈 | 空选确定时提示选择答案。确定后锁定选项，显示对错、正确答案和已选答案；返回同一题时仍可看反馈。展开解析按钮位于操作栏末尾，作答前点击会提示先作答。未调用旧 AI 服务。见[答题反馈](baseline/practice-feedback-390-light.png)。 |
| 错题、收藏 | 实际答错进入错题集，收藏后进入收藏夹。进入错题练习，同一题第一次答对仍保留，再答对移出。取消收藏后列表恢复空态。 |
| 总题库 | 中文关键词、单选、已做及收藏筛选组合可找回同一题。显示答案后高亮正确项，隐藏时撤去高亮。见[搜索与答案](baseline/library-search-390-light.png)。 |
| 模拟考试 | 从考试入口生成 50 个不同旧题 ID，页面正向计时、不限时。单选选择后自动推进，多选点确定后推进；可跳题、标记、收藏。交卷前考题区域不显示正确项和答案反馈。见[考试入口](baseline/exam-start-390-light.png)和[考试进行中](baseline/exam-question-390-light.png)。 |
| 草稿与结果 | 离开考试确认后可以继续上次考试。考试页刷新自动恢复当前题、已答数和标记。作对两题后交卷，确认未答 48 题，结果为 2/50 分；仅错题视图列出 48 项。返回并打开历史详情可看到同一份成绩。见[考试结果](baseline/exam-result-390-light.png)。 |
| 离线练习 | 在题库已下载的打开页面中断网，可以作答、看到反馈并切题。全新浏览器首次打开后，Service Worker 已接管但尚无缓存首页，此时离线刷新失败。先恢复网络，让受控页面成功导航并缓存首页，此后离线刷新可恢复题库、已答、收藏和当前进度。 |
| 友情赞助 | 页脚入口打开 `#sponsor`，显示“友情赞助”、原收款图和“返回练习”。返回按钮清除 hash 并恢复之前的练习页。见[赞助页](baseline/sponsor-390-light.png)。 |

## 重构对照范围

将变更后的题目文字、专题、题量、模拟试卷内容和新标识排除在截图逐像素对比之外。页首删除产品版本徽标，原主题按钮保留，新增账号入口。页脚替换旧存储说明，保留赞助入口。解析沿用题卡操作栏与答后展开或收起的行为，内容由数据库提供。登录、同步状态、离线缓存提示及由分页产生的控件按新流程单独验收。320 px 下的导航折行作为旧站记录，新站仍须保持无溢出和语义可读。

本轮实测覆盖桌面浏览器的响应式视口和本地 HTTP 流程。微信扫码、真机 Safari 和线上访问待验证。

## 新界面本地复测

在 `tmp/study-ui-fixture/` 的独立 Next.js 应用中，使用 Chromium 和隔离的 HTTP 契约测试数据验证新界面。此测试使用测试身份，生产应用保留服务端登录和邮箱验证门槛。

- 在表中的 5 个视口分别验证明暗主题、导航和练习界面的横向尺寸。已目视对照 320 px 深色、1440 px 浅色和 390 px 赞助页。
- 实际操作单选互斥、答后反馈、逐项解析、跳题和刷新续接、收藏、错题、搜索筛选与分页。模拟断网作答，联网后请求携带队列所有者；服务端终止型拒绝会显示保存失败状态。
- 实际操作 50 题模拟考试的单选推进、多选确认、标记、刷新恢复、离开后续答、交卷及错题复盘。样本试卷得分 2/50，错题视图显示 48 道。
- 使用合成题库批次验证清单和分片 SHA-256 检查、下一批预取、联网后的发布更新及原作答 `contentRevision`。违规分片路径或摘要不符时回源真实 API 路径。

这些结果覆盖交互和 HTTP 契约。在线部署、真实账号、数据库、CDN 命中和大陆网络结果以各自的验收记录为准。
