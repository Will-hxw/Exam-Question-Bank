## T08 可以从轻或减轻的情形

草稿 `f823bff6-f3c4-490f-a51a-bc80de3bdaba` 现有 A、B、D 正确。让每个选项独立满足对应条款保留的事实。A 与 B 适用不同项，可能同时出现，无须互斥。题干保留“可以”，避免自动认定实际处分结果。 [S19 第十七、二十、四十条](https://www.12371.cn/2023/12/27/ARTI1703688691926144.shtml)

**建议题面**　依《纪律处分条例》第十七条，仅据各项所列情形，哪些可作为从轻或减轻处分的依据（多选）？

| 选项 | 判定与逐项解析 |
| --- | --- |
| A 组织谈话函询和初核前，交代本人应受党纪处分的问题 | 正确。第十七条第（一）项认定主动交代为可适用情形。第四十条还规定，谈话函询、初核或立案审查期间交代组织未掌握的问题，也属于主动交代。 |
| B 初核时配合核实并如实说明本人违纪违法事实 | 正确。第十七条第（二）项要求配合与如实说明，两者同时具备。该项还涵盖组织谈话函询和立案审查。 |
| C 拒不退赔违纪所得 | 第二十条第（二）项将拒不上交或者退赔列为应当从重或者加重处分的情形。 |
| D 主动退赔违纪所得 | 正确。第十七条第（五）项列明主动上交或退赔，适用的是“可以”。 |

第十九条第一款另设免予党纪处分入口，前提包括原拟警告或严重警告等规定条件，并要求书面结论。其第三款所列不可抗力等原因导致、且无故意或过失的情形属于不追究责任。第二十二条的从轻在处分幅度内，第二十三条的减轻在幅度外减一档；法定只有开除党籍一个档次的行为排除该减轻规则。这些规则各有条件，均不作为本题第十七条的可选情形。 [S19 第十九、二十二、二十三条](https://www.12371.cn/2023/12/27/ARTI1703688691926144.shtml)
